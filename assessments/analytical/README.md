# Analytical Assignments

Eight written assignments covering the analytical skills the course expects: comparing algorithms,
analysing complexity, deriving mathematics, evaluating models, analysing errors, auditing datasets,
reading papers and reviewing architectures. No assignment requires more than a calculator and a text
editor, though several are easier with a plotting tool.

## Marking

Rubrics are weighted and sum to 100%; passing is 60%. Every numerical claim must be computed or
cited, and every assumption must be stated. Length limits are part of the task: a report over the
limit is marked only to the limit.

Reference answers are not published for analytical assignments; the rubric names what a strong answer
contains. See the [solutions policy](../README.md#solutions-policy).
