## How to work an assignment

1. Read the whole brief before writing code; the constraints often decide the design.
2. Write the smallest version that produces one number, then extend it.
3. Keep a run log: command, seed, result. Untraceable numbers do not count.
4. Write the report as you go, not at the end.

## Marking

Rubrics are weighted and sum to 100%. Passing is 60%. The deliverable list is the minimum: a
submission that omits a required artefact loses that criterion's marks even if the code is good.

Solutions and reference approaches are not published for programming assignments; the marking
criteria and hints in each brief are the guidance. See the [solutions policy](../README.md#solutions-policy).
