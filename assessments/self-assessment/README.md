# Self-Assessment

One sheet per module. Each has five sections: a key-concepts checklist, five knowledge-check
questions, a practical competency checklist, suggested revision topics, and a readiness test for the
next module. Nothing here is marked; it is a diagnostic you run on yourself.

## How to use a sheet

1. Fill it in **before** revising, so the gaps are honest.
2. Revise only the items you marked *Shaky* or *Not yet*; re-read the linked lesson, then re-answer.
3. Take the readiness test without notes. If you cannot do all three items, delay the next module by
   a day rather than carrying the gap forward.
4. Re-run the sheet after the module quiz; the two should agree. If they disagree, trust the quiz's
   evidence and revisit the lesson it points to.
