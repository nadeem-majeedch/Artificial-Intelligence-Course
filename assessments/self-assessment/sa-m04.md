# SA-M04 — Self-Assessment: Knowledge-Based Systems

Module M04 · [Module](../../docs/CURRICULUM-MAP.md) · [Quiz](../quizzes/quiz-m04.md) · [Index](README.md)

Rate each item **Confident / Shaky / Not yet**.

## Key concepts checklist

- [ ] Translate a policy sentence into a logical formula
- [ ] Distinguish syntax, semantics and entailment
- [ ] Run forward and backward chaining by hand
- [ ] Explain why Horn clauses make inference tractable
- [ ] Describe how a rule base can be inconsistent or incomplete
- [ ] Identify where a rule base is the wrong tool

## Knowledge-check questions

1. Give a sentence in propositional logic and state its models.
2. Why does forward chaining terminate on a finite Horn clause set?
3. What is the difference between a rule firing and a rule being relevant?
4. Construct a rule base with two rules that can derive a contradiction.
5. Why can't a rule base express "approximately below 30,000" without extension?

## Practical competency checklist

- [ ] Encode a small rule base from a written policy
- [ ] Generate a derivation trace automatically
- [ ] Detect unreachable rules
- [ ] Present an explanation that names the rule and its triggering facts

## Suggested revision topics

Propositional logic · entailment · Horn clauses · forward vs backward chaining · conflict and
unreachability · explanation · limits of symbolic rules.

## Readiness test for M05

Without notes:

1. Convert three policy sentences into rules and check them against two cases.
2. Trace forward chaining and list the firing order.
3. Explain one situation where a probabilistic model beats a rule base, and one where the reverse
   holds.

If any is shaky, revisit L04-04 and L04-06 before M05.
