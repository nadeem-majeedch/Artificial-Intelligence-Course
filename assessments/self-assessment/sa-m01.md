# SA-M01 — Self-Assessment: Introduction and Foundations

Module M01 · [Module](../../modules/M01-introduction-and-foundations/README.md) · [Quiz](../quizzes/quiz-m01.md) · [Index](README.md)

Rate each item **Confident / Shaky / Not yet**. Shaky or "not yet" items are your revision list.

## Key concepts checklist

- [ ] Define AI and distinguish it from automation and ordinary software
- [ ] Describe the agent–environment framing and why it is useful
- [ ] Name the main subfields and what each optimises
- [ ] Explain narrow vs general AI without overclaiming
- [ ] Summarise the historical phases and what ended each one
- [ ] State the difference between a model, an algorithm and a system
- [ ] Explain why evaluation is part of the definition of progress

## Knowledge-check questions

1. What does it mean to say a system is "intelligent" in this course's framing?
2. Give an example of a task that looks hard to humans and is easy for computers, and the reverse.
3. Why did expert systems stall, and which two problems did they expose?
4. Distinguish a benchmark improvement from a capability improvement.
5. What is the difference between an AI model and an AI product?

## Practical competency checklist

- [ ] Run a Python script that reads a CSV and reports basic statistics
- [ ] Use Git to track a change without committing to a remote
- [ ] Read an API or dataset description and state its limitations
- [ ] Write a one-paragraph problem statement with inputs, outputs and success criteria

## Suggested revision topics

Agent–environment framing · narrow vs general · history and the "AI winters" · benchmarks and their
limits · model vs system · the course's evidence standard.

## Readiness test for M02

You are ready when you can, without notes:

1. Draw the agent–environment loop and label percepts and actions.
2. Explain why a benchmark score alone cannot establish usefulness.
3. Give one example where a system's stated goal and its measured objective diverge.

If any of the three is shaky, revisit L01-01 and L01-05 before starting M02.
