# SA-M02 — Self-Assessment: Intelligent Agents

Rate each item **Confident / Shaky / Not yet**.

## Key concepts checklist

- [ ] Write a PEAS description for a stated task
- [ ] Classify an environment on the standard dimensions
- [ ] Distinguish reflex, model-based, goal-based and utility-based agents
- [ ] Explain what an internal state estimate buys under partial observability
- [ ] Describe the rational-agent standard and its dependence on the performance measure
- [ ] Identify when a simpler architecture is the right choice

## Knowledge-check questions

1. Write the PEAS description for a warehouse picking robot.
2. Is a chess engine's environment fully or partially observable? Justify.
3. What does a model-based agent maintain that a reflex agent does not, and why does it help?
4. Why is "maximise the performance measure" incomplete without a time horizon?
5. Give an example where a utility-based agent and a goal-based agent choose differently.

## Practical competency checklist

- [ ] Implement a simple agent loop against a simulated environment
- [ ] Define a single-number performance measure and defend it
- [ ] Run the same agent on multiple seeds and report the distribution
- [ ] Print a trace that shows percept, state, action for each step

## Suggested revision topics

PEAS · environment dimensions · agent architectures · rationality and performance measures ·
state estimation · exploration vs exploitation in agent design.

Without notes:

2. Explain why partial observability forces internal state.
