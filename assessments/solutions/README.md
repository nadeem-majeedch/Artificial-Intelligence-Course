## How the explanations are written

Each answer gives the correct option or value, the reason, and — for multiple choice — why the
distractors are wrong. Numerical answers show the arithmetic with intermediate values. Where a
question tests a judgement, the key gives a model answer with the marks attached to the reasoning
rather than the wording.

## Marking short answers

Award marks for the mechanism, not the phrasing. A correct conclusion with no reasoning earns at most
half. An answer that names the right concept but applies it to the wrong quantity earns nothing for
the application mark: read the working.

## Related material

Some explanations quote figures measured in the module notebooks (for example the M13 fairness gaps
and the M14 compression numbers). Those figures are reproducible from the module code; they are
included so the explanation can be checked against a running system rather than taken on trust.
