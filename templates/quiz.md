## How to use this quiz

Answer on paper first, without looking anything up. Then open each answer, mark yourself, and use
the revision table at the end to decide what to reread. A quiz you score without effort teaches
you nothing — the point is to find the gaps.

**Scoring guide**

| Score | What it means |
| :--- | :--- |
| «80%+» | Move on to the next module |
| «60–79%» | Reread §3 of the lessons you missed and redo their notebook exercises |
| «below 60%» | Work through the module again; check the readiness self-check in the module README |
