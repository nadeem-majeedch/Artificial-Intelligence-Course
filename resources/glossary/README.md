# Glossary — detailed entries

This is the expanded glossary. Every entry gives the term, its abbreviation, a one-sentence
definition, the mechanism in more detail, the mathematics where a formula is the clearest
statement, a worked practical example, related terms, and the lesson where the idea is taught.

For a one-line lookup across all 326 course terms, use the [quick-reference glossary](../glossary.md).

## Entry format

```text
### Term (ABBR)
**Abbreviation.** ABBR · **Module.** M06
**Simple definition.** one sentence a beginner can use
**Detailed explanation.** the mechanism, why it exists, and its main limitation
**Mathematics.** the formula, or "—" where no formula is the clearest statement
**Practical example.** a concrete case with numbers or a named system
**Related.** links to other entries
**Where it is taught.** a link to the lesson, or the module page if the lesson is not published
```

## Modules without published lessons

M03 (search), M05 (uncertainty) and M09 (vision) have no lessons in this repository yet, and
M08, M10, M12 have reference code but no lessons. Their glossary entries link to the module page
and are marked **module page only**. They are included because the terminology is part of the
course's intended vocabulary, and because the quizzes already use it.
