## Scenario

A regional courier company runs 240 deliveries a day from one depot on a 12×12 street grid. Drivers
currently follow a fixed route sheet written years ago. The operations manager suspects the routes
are 20–30% longer than necessary but has no way to check, and the last time the company bought
"route optimisation" software it produced routes that ignored one-way streets.

She asks you for two things: **the shortest legal route between two points on the grid**, and
**evidence about how much the current route sheet costs**. She is not technical, and she will
compare your numbers with the fuel bill.

## Your role

You are the analyst. You report to the operations manager and you will be judged on whether your
evidence is reproducible and whether you state the limits of the model.

## What you are given

| Item | Details |
| :--- | :--- |
| Grid | 12×12, 4-connected, unit cost per block |
| Obstacles | one-way segments and blocked streets, supplied as a set of coordinates |
| Reference code | `code/search_algorithms.py` — BFS, DFS, UCS, A*, greedy |
| Benchmark | nine start/goal pairs with the optimal cost known |

**Not provided:** real traffic data, turn penalties, or the current route sheet. Those are stated as
unknowns in your report, not invented.

## Requirements

- **R1** Implement the grid adjacency with obstacles and verify it is symmetric where the street is two-way.
- **R2** Run BFS, UCS and A* on all nine benchmark pairs; report path cost, nodes expanded and peak frontier.
- **R3** Prove your A* heuristic admissible, and test one inadmissible variant.
- **R4** Report the cost ratio between the fixed route sheet (given as a list of waypoint orders) and your optimal route, with the method used to normalise for distance.
- **R5** State three assumptions the model makes and one decision it could get wrong.

## Tasks

1. **Build the graph** (20 min). Load the obstacle set, construct neighbours, assert that no node
   is isolated. Success: `len(nodes) == 144 - blocked` and no exception on unreachable pairs.
2. **Baseline** (15 min). Run BFS. Record cost and nodes expanded for all nine pairs.
3. **Compare** (30 min). Run UCS, A*, and greedy best-first. Fill the table in §5.
4. **Heuristic audit** (20 min). Prove Manhattan is admissible on this grid; run A* with
   `h = 3 × Manhattan` and report any instance where the returned cost exceeds the optimum.
5. **Inadmissible failure** (15 min). Explain, for the failing instance, exactly which node was
   discarded and why the pruning was invalid.
6. **Verdict** (20 min). Write the three sentences you would send the operations manager.

## Expected results

- BFS and UCS return identical costs on every pair (unit costs).
- A* expands strictly fewer nodes than UCS on all nine pairs; on the open grid the ratio is roughly 2–3×.
- Greedy returns a valid path that is 1–3 blocks longer than optimal on at least two pairs.
- With `h = 3 × Manhattan`, at least one pair returns a suboptimal cost.

## Extension challenges

1. Add turn penalties (a left turn costs 0.5 extra) and explain why the state space must now include direction.
2. Replace unit costs with travel times and show that BFS is no longer optimal.
3. Run A* with a weight of 1.2 on the heuristic and measure the cost/expansion trade-off.

## Reflection

1. Which requirement forced you to think about the model rather than the algorithm?
2. The manager wants one number. What is the most honest single number you can give, and what does it hide?
3. Where would this analysis be wrong in a real city?
