## 3. Conceptual Explanation

### 3.1 One loop, five strategies

Every uninformed algorithm below is the loop from L03-01. The only difference is **which node
leaves the frontier**, which is exactly the choice of data structure:

| Algorithm | Frontier | Removes | Complete? | Optimal? | Time | Space |
| :--- | :--- | :--- | :---: | :---: | :--- | :--- |
| Breadth-first | FIFO queue | oldest | yes | yes (unit cost) | $O(b^d)$ | $O(b^d)$ |
| Depth-first | LIFO stack | newest | no (loops) | no | $O(b^m)$ | $O(bm)$ |
| Uniform-cost | priority queue on $g$ | cheapest $g$ | yes | yes | $O(b^{1+\lfloor C^*/\epsilon \rfloor})$ | same |
| Depth-limited | stack + depth counter | newest | no | no | $O(b^\ell)$ | $O(b\ell)$ |
| Iterative deepening | repeated DLS | — | yes | yes (unit cost) | $O(b^d)$ | $O(bd)$ |

Here $b$ is branching factor, $d$ the shallowest solution depth, $m$ the maximum depth, $\ell$ the
limit, $C^*$ the optimal cost and $\epsilon$ the smallest step cost.

### 3.2 The memory argument that decides most cases

Breadth-first and iterative deepening have the same time complexity, but their space complexity
differs by a factor of $b$: BFS stores an entire level, IDS stores one path plus siblings. At
$b = 10$, $d = 10$, BFS needs about 10 billion nodes in memory; IDS needs about 100. That is the
whole reason iterative deepening exists, and why "BFS is optimal" is not an argument for using it.

### 3.3 Why DFS fails and how depth-limiting fixes it

Plain DFS in a graph with cycles will loop forever. Marking visited states fixes the loop but
still allows a solution at depth 40 to be found before one at depth 3. Depth-limiting caps the
damage; iterative deepening removes the cap while keeping DFS's memory profile by re-running with
increasing limits.

### 3.4 Uniform-cost search is Dijkstra

UCS expands the node with the smallest $g$ and is optimal for non-negative costs. It degenerates to
BFS when every step costs the same, and the goal test must happen on expansion, not generation —
otherwise a cheaper path to the same goal can be discarded.

## 4. Pseudocode

```text
function BFS(problem):
    frontier <- FIFO([root]); explored <- {}
    while frontier not empty:
        node <- frontier.pop_left()
        if goal(node.state): return node
        explored.add(node.state)
        for child in expand(node):
            if child.state not in explored and child.state not in frontier:
                frontier.push_right(child)

function IDS(problem):
    for limit in 0, 1, 2, ...:
        result <- DEPTH_LIMITED(problem, limit)
        if result is a solution: return result
```

## 5. Worked Example — a small graph, three strategies

Graph: `A` → `B`, `C`; `B` → `D`, `E`; `C` → `F`; goal is `F`. Unit costs, alphabetical tie-break.

- **BFS:** A, B, C, D, E, F — expands 6 nodes, finds F at depth 2.
- **DFS:** A, B, D, E, C, F — expands 6 nodes, also depth 2 here, but on a deep branch it can wander far.
- **UCS** with costs A→B 4, A→C 1, C→F 2: expands C (1) before B (4), reaches F with cost 3, which is optimal.
- **DLS(limit=1):** explores A, B, C and fails — the goal is at depth 2, outside the limit.

**Numbers to check yourself.** For $b = 2$, $d = 10$: BFS frontier peak ≈ 2,048 nodes; IDS total
expansions ≈ $2^{11} - 1 = 2{,}047$ nodes but a frontier of at most 11.

## 6. Mathematical Formulation

Nodes generated by breadth-first to depth $d$:

$$N_{BFS} = 1 + b + b^2 + \cdots + b^d = \frac{b^{d+1} - 1}{b - 1}$$

Iterative deepening repeats the upper levels; the total is dominated by the last iteration:

$$N_{IDS} = \sum_{i=0}^{d} \frac{b^{i+1} - 1}{b - 1} \approx \frac{b^{d+1}}{(b-1)^2}$$

The ratio $N_{IDS}/N_{BFS} \approx b/(b-1)$: at $b = 10$ that is 11% more work for orders of
magnitude less memory.

## 7. Python Implementation

```python
from collections import deque


def bfs(graph, start, goal):
    frontier = deque([[start]])
    explored = {start}
    while frontier:
        path = frontier.popleft()
        node = path[-1]
        if node == goal:
            return path
        for nxt in graph[node]:
            if nxt not in explored:
                explored.add(nxt)
                frontier.append(path + [nxt])
    return None


def dfs(graph, start, goal):
    frontier = [[start]]
    explored = set()
    while frontier:
        path = frontier.pop()
        node = path[-1]
        if node == goal:
            return path
        if node in explored:
            continue
        explored.add(node)
        for nxt in reversed(graph[node]):
            frontier.append(path + [nxt])
    return None


def ids(graph, start, goal, max_depth=12):
    def dls(path, limit):
        node = path[-1]
        if node == goal:
            return path
        if limit == 0:
            return None
        for nxt in graph[node]:
            if nxt not in path:               # path check, not global explored
                found = dls(path + [nxt], limit - 1)
                if found:
                    return found
        return None
    for limit in range(max_depth + 1):
        found = dls([start], limit)
        if found:
            return found, limit
    return None, max_depth


GRAPH = {"A": ["B", "C"], "B": ["D", "E"], "C": ["F"], "D": [], "E": [], "F": []}
print("BFS:", bfs(GRAPH, "A", "F"))
print("DFS:", dfs(GRAPH, "A", "F"))
print("IDS:", ids(GRAPH, "A", "F"))
```

```text
BFS: ['A', 'C', 'F']
DFS: ['A', 'B', 'D', 'E', 'C', 'F']
IDS: (['A', 'C', 'F'], 2)
```

## 8. Practical Applications

- **Filesystem and dependency traversal** — DFS, because memory grows with depth, not breadth.
- **Shortest route by time** — UCS or A\*; BFS only if every edge costs the same.
- **Puzzle solvers** — iterative deepening when memory is the binding constraint.
- **Web crawling** — BFS for politeness and depth limits; DFS risks deep, low-value branches.

## 9. Common Mistakes

- Testing the goal when generating a child in UCS, which breaks optimality.
- Using a global `explored` set inside iterative deepening, which makes later iterations fail.
- Comparing algorithms by time complexity while ignoring space, then running out of memory at depth 9.
- Assuming DFS is complete because it is complete on trees.
- Forgetting that BFS optimality needs unit step costs.
