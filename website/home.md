## A course built for understanding

Artificial Intelligence is broad: search and planning, knowledge representation, reasoning under
uncertainty, machine learning, perception, language, reinforcement learning, generative models and
multi-agent systems. This course teaches that breadth in a deliberate order, so each idea arrives
with the background it needs.

It is written for a reader who does not have an instructor in the room. Lessons begin with
intuition, work through examples by hand and then implement the idea in Python. Laboratories place
the idea in a realistic scenario with requirements, a deliverable and a rubric. The capstone asks
you to scope, build, evaluate and defend a complete AI system.

## Course learning outcomes

On completing the course, you should be able to:

| ID | Outcome |
| :--- | :--- |
| CLO1 | Explain what AI is, how the field evolved, and how agents perceive, decide and act. |
| CLO2 | Formulate a search or constraint problem and justify an algorithm with its trade-offs. |
| CLO3 | Represent knowledge in propositional and first-order logic and derive sound conclusions. |
| CLO4 | Quantify uncertainty, build and query Bayesian networks, and design fuzzy inference systems. |
| CLO5 | Run a leakage-free machine-learning workflow and evaluate models with appropriate metrics. |
| CLO6 | Build, train, debug and evaluate neural networks for tabular, text and image data. |
| CLO7 | Implement reinforcement-learning and generative systems, and assemble a tool-using agent. |
| CLO8 | Audit an AI system for fairness, explainability, privacy and security, and deliver a capstone. |

## Prerequisites

No previous artificial-intelligence course is assumed. You should be able to write and run a
short Python program, read algebraic notation, and work with fractions, functions and basic
probability. The first modules teach the AI-specific ideas from the beginning.

If you need to strengthen your background, start with the [prerequisite track](prerequisites/README.md)
and take the [readiness diagnostic](prerequisites/diagnostic.md). P01 covers Python and data tools,
P02 the mathematics, P03 probability and statistics, and P04 data preparation and visualisation.

## Learning methodology

<div class="grid cards" markdown>

-   **1. Derive**

    ---

    Read the intuition and formal statement, then reproduce the worked example on paper with the
    solution covered.

-   **2. Implement**

    ---

    Run the lesson code and notebook. Change one parameter, predict the effect and compare.

-   **3. Break**

    ---

    Remove a term, transpose a matrix or corrupt the labels. Read the failure and repair it.

-   **4. Measure and defend**

    ---

    Report a baseline, a primary metric, subgroup results, uncertainty and a limitation. Every lab
    and the capstone are marked on this evidence.

</div>

## Laboratories, projects and assessment

The practical layer is not optional. The course includes 38 module laboratories, 22 assignments,
14 quizzes, 14 self-assessment sets, 8 module projects and 12 capstone briefs.

- **Laboratories** give you a stakeholder, constraints, a deliverable and a rubric. Start with the
  [laboratory guide](laboratories.md).
- **Assignments** ask for a reproducible pipeline and a defended result, not only working code.
  Browse the [assignment catalogue](assignments.md).
- **Quizzes and self-assessment** diagnose gaps and point back to the lesson to revisit. See
  [quizzes and self-assessment](quizzes-and-self-assessment.md).
- **Projects and capstones** build a portfolio; the [capstone studio](projects-and-capstones.md)
  contains the briefs, milestones, rubric and report guidance.

## Software requirements

| Essential | Optional or module-specific |
| :--- | :--- |
| Python 3.11+ | Hugging Face `transformers` and `sentence-transformers` for M08/M11 demonstrations |
| Jupyter Notebook, JupyterLab or VS Code | Gymnasium for M10 benchmarks |
| NumPy, pandas and Matplotlib | NetworkX for M14 graph inspection |
| scikit-learn (from M06) | GPU for larger experiments; never required |
| PyTorch CPU build (from M07) | — |

Everything runs on a CPU. Most notebooks finish in seconds; the longest take about 1–1.5 minutes on
the release-audit machine. Two M11 notebooks download small pretrained weights on first use and then
run offline. No paid API account is required.
