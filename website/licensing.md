# Licensing and Attribution

This repository contains four kinds of material. There is **no single repository-wide licence**.
Each layer has its own terms, and third-party material is never relicensed by the course.

## At a glance

| Material | Licence | What it covers |
| :--- | :--- | :--- |
| Original source code | **MIT** | Python files, tests, audit scripts and notebook code cells |
| Original educational content | **CC BY 4.0** | Lessons, labs, assignments, quizzes, documentation and notebook prose |
| Original synthetic datasets | **CC0 1.0** | Data generated by seeded course code, including the committed samples |
| Third-party material | **Upstream terms** | Dependencies, external datasets, model weights, papers and quotations |

## Reusing the course

Under **CC BY 4.0**, you may copy, redistribute, adapt and teach from the educational content,
including commercially, provided you:

1. name the author — Muhammad Nadeem Majeed;
2. name the work — *Artificial Intelligence — A Comprehensive Course*;
3. link the source repository;
4. link to CC BY 4.0;
5. indicate any changes you made.

Suggested attribution:

> Adapted from *Artificial Intelligence — A Comprehensive Course* by Muhammad Nadeem Majeed
> (University of the Punjab, PUCIT), licensed under CC BY 4.0. Changes: [describe changes]. Source:
> https://github.com/nadeem-majeedch/Artificial-Intelligence-Course

There is no share-alike condition. The licence does not imply endorsement and does not grant rights
over third-party material.

## Code and data

The MIT licence applies to original source code. Keep the copyright and permission notice with
copies and substantial portions of the code.

Original synthetic datasets are dedicated to the public domain under CC0 1.0. You may copy, modify
and distribute them without attribution, although attribution is welcome. CC0 does **not** cover
external datasets, pretrained model weights or student work.

## Third-party material

Dependencies, UCI datasets, pretrained models, papers and quotations remain subject to their own
terms. In particular:

- UCI digits and Iris are CC BY 4.0 and are not redistributed in this repository.
- Pretrained model weights are downloaded at runtime; weights and fine-tunes have their own
  model-card terms.
- Model outputs are not automatically covered by the weights' licence and are not relicensed by
  this course.
- Bibliographic entries are citations, not permission to redistribute the cited work.

The full register, including verification dates and model-card restrictions, is in
[THIRD-PARTY-ATTRIBUTIONS.md](THIRD-PARTY-ATTRIBUTIONS.md).

## Citation

If you use the course in teaching or research, cite it using [CITATION.cff](CITATION.cff). The
software licence field in that file refers to the original source code; educational content and
datasets retain their separate licences.
