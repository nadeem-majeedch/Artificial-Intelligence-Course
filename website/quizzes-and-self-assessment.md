# Quizzes and Self-Assessment

Assessment in this course is diagnostic. A low quiz score is useful information: it identifies the
lesson to revisit. Answer without looking anything up, then mark yourself with the explained key.

## How to mark yourself

1. Answer on paper with no notes.
2. Mark against the explained key, not only the letter.
3. Record the lesson and exercise named by each wrong answer.
4. Revisit the lesson and attempt a fresh example before retrying the quiz.
5. Below 60% is a signal to review, not a verdict on your ability.

!!! tip "Retrieval beats rereading"
    Redo two questions from an earlier module each week. Forgetting is normal; recovering the idea
    deliberately is the skill the assessment is training.
